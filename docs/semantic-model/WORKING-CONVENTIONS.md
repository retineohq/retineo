# Retineo Memory Core — Working Conventions

> Инструкция по работе с проектом. Конфликтов с HANDOFF не имеет.

## Repository & Openness

- Develop Retineo in a public GitHub repository from the start.
- Protocol, Node, schemas, tests, examples and core implementation are open-source.
- Keep only secrets, deployment credentials, and genuinely commercial/enterprise components private.
- Do not create a private "prototype" repository first.
