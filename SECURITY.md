# Security Policy

## Supported Versions

Only the latest released version of `@retineo/core` receives security updates. Please keep your installation up to date.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately via email:

**kot.valery@gmail.com**

Please include:
- A description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact
- Suggested fix (if any)

We aim to acknowledge reports within 48 hours and provide a timeline for resolution within 7 days.

## Disclosure Policy

- Reports will be kept confidential until a fix is released.
- Credit will be given to the reporter unless anonymity is requested.
- Fixes will be released as a patch version and announced in the CHANGELOG.
